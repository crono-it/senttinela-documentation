# MVP

## Objetivo

El MVP de Senttinela busca permitir que una organización registre y comprenda de forma simple sus movimientos de dinero con otras entidades.

Senttinela prioriza una experiencia comprensible para personas que no necesariamente poseen conocimientos contables.

## Capacidades

El MVP permite:

- registrar entidades;
- registrar artículos;
- registrar ingresos;
- registrar egresos;
- asociar artículos a los movimientos;
- registrar movimientos pendientes o pagados;
- registrar pagos posteriores;
- consultar el historial de movimientos de una entidad;
- visualizar el flujo de ingresos y egresos efectivos de la organización.

## Fuera del alcance actual

El MVP no pretende todavía resolver:

- contabilidad formal;
- facturación;
- gestión tributaria;
- conciliación bancaria;
- inventario avanzado;
- producción;
- automatización contable.

Estas capacidades podrán evaluarse a partir del uso real y de las necesidades observadas.
